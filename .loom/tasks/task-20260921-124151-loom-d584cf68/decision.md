# 결정

- 사용자 지시에 따라 현래님 녹음은 연진님 녹음과 별개의 TXT로 전사했다.
- 이전 Task에서 자동 승인 검토가 외부 Pi/OpenAI 전송을 거부했으므로 같은 경로를 우회하지 않았다. `--local-only` 옵션으로 OpenSuperWhisper만 사용하고, 텍스트 후보를 로컬에서 비교했다.
- 정확 모드의 5개 후보를 구간마다 확인했다. 원본 후보가 문장을 누락한 구간은 보정·세부·문맥 후보로 복원했다. 사람 이름과 어휘가 갈리는 곳은 확정하지 않고 `확인 필요`로 남겼다.
- 이 Task가 만든 자동 초안 TXT를 `--local-only --replace`로 검수본으로 갱신했다. 원본 녹음과 모델 설정은 바꾸지 않았다.
