# 결정

- 세 페이지의 `pb-16`을 줄이는 대신 공통 레이아웃을 수정했다. 해당 패딩은 콘텐츠와 푸터 사이의 의도된 간격이고, 실제 원인은 짧은 문서에서 `main`이 뷰포트의 남은 높이를 채우지 않는 구조였다.
- 기존 Tailwind 유틸리티만 사용해 `body`에 `flex flex-col`, `main`에 `flex-1`을 추가했다.
- 페이지별 마크업, 카드, 빈 상태, Sanity 조회는 변경하지 않았다.
- Astro 공식 스타일링 지침에 맞춰 기존 전역 Tailwind 스타일 흐름을 유지하고 새 전역 CSS 규칙은 추가하지 않았다.
