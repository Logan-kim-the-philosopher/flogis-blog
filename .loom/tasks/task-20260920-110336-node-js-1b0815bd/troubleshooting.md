# 문제 해결 기록

- 원음 전사만으로는 일부 참여자 질문이 짧게 누락되거나 강의 문장이 반복 인식됐다. 동일 음성을 `highpass=f=100,dynaudnorm=f=150:g=21`로 보정한 1분 구간으로 다시 전사해 비교했다.
- 보정본이 항상 더 정확하지는 않아 39개 원음 구간마다 대응하는 보정본 두 구간의 글자 수와 문장 경계를 비교했다. 반복·환각 문장이 있는 구간은 원음으로 되돌렸다.
- 자동 인식 결과에서 확정할 수 없는 시작 전 잡담과 일부 질의응답은 내용을 만들어내지 않고 불명확 표기로 보존했다.
- OpenSuperWhisper 실행 과정에서 저장소 루트에 생성된 `default.profraw`는 전사 도구의 임시 프로파일 산출물임을 확인하고 제거했다.
