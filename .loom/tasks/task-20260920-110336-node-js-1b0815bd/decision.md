# 결정 사항

- 원음은 2분 단위로 전사해 강의 문맥을 유지하고, 작은 목소리 누락을 찾기 위해 고역 통과 및 동적 음량 보정을 적용한 1분 단위 전사를 추가로 생성했다.
- 구간별 원음·보정본의 길이와 시작·끝 문장을 비교해 더 충실한 결과를 선택했으며, 반복 인식이 생긴 보정 구간은 원음 결과를 사용했다.
- 화자를 확실히 구분할 근거가 없어 임의의 화자 이름을 붙이지 않았다.
- 문맥상 명확한 `Node.js`, `JavaScript`, `HTML`, `CSS`, `V8`, `DOM`, `npm`, `Express`, `NestJS`, `Vite`, `ESLint`, `TypeScript` 등의 용어만 교정했다. 겹친 말이나 작은 질의응답은 추정하지 않고 `[발화 불명확]` 계열 표기로 남겼다.
- 원본은 수정하지 않고 최종 UTF-8 텍스트 파일 하나만 바탕화면에 추가했다.
