# 주요 결정

1. 두 원본 모두 `project_meeting`으로 분류했다.
   - 최종 발표 원본은 발표 시연 단계와 역할·리허설을 확정하는 내용이다.
   - Cody Stat 원본은 OHAYO 운영 인수와 플랫폼·조직 설계 논의가 중심이다.
2. 최종 발표 글의 핵심 서사는 `5단계 하네스 생성 → 단계별 뷰어 → 6단계 실행 UI → 약 20분 OHAYO 데모`로 정리했다.
3. Cody Stat 글에서는 실제로 확정된 OHAYO 운영·알림·권한 분담과, 아직 합의되지 않은 앱스토어형 게이트웨이·복수 조직 제안을 명확히 분리했다.
4. 참여자 참조는 production Sanity의 기존 person 문서만 사용했다.
   - 최종 발표: 홍용재, 김희성, 김정현
   - Cody Stat: 홍용재, 허연진, 김희성, 김정현
   - 직접 식별할 수 없는 추가 발화자는 임의로 person 문서를 만들지 않았다.
5. 원문에 없는 결론·담당자·기한을 만들지 않았고, 상대 날짜는 회의일 `2026-09-03`을 기준으로 명시 날짜로 정규화했다.
6. 실제 내용과 연결되는 이미지가 없어 `coverImage`를 비워 두었다.
7. Pi 외부 프로세스 사용 승인이 거절된 뒤 원문을 추가 외부 프로세스로 전송하지 않고, 현재 Codex 세션에서 직접 구간별 검토해 구조화했다.
