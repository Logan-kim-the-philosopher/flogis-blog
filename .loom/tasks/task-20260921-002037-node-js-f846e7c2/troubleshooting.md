# 문제 해결 기록

- OpenSuperWhisper `bench`의 최초 sandbox 실행이 출력 없이 exit 134로 종료됐다. macOS 앱과 로컬 모델 실행 권한이 필요한 것으로 확인하고 승인된 앱 실행으로 다시 수행해 정상 완료했다.
- OpenSuperWhisper `bench`는 진행 중 출력 없이 완료 시 JSON을 반환하므로 실행 세션 상태를 주기적으로 확인했다.
- 약 1분 음량 보정 전사에서 팀 대화의 `00:14:19` 전후 한 구간이 비었다. 같은 구간의 약 2분 원음과 30초 정밀 전사는 비어 있지 않아 두 결과를 대조해 복구했다.
- 짧은 구간 전사가 항상 더 정확하지는 않았다. 반복되거나 앞뒤 문맥이 끊긴 표현은 더 긴 원음 결과를 우선하고, 작은 발화가 살아난 경우에만 보정·정밀 결과를 반영했다.
