# 결정 사항

- 마지막에 몇 초짜리 조각이 생기지 않도록 각 원본 길이를 균등 분할했다. 팀 대화는 원음 11개·보정본 21개·정밀본 41개, Node.js 피드백은 원음 2개·보정본 4개·정밀본 8개로 전사했다.
- 음량 보정은 `highpass=f=100,dynaudnorm=f=150:g=21`을 적용했으며 보정본을 정답으로 간주하지 않고 원음 결과와 비교했다.
- 팀 대화 후반 화면 공유 구간에서 보정본 한 구간이 비어 원음과 30초 정밀 전사를 사용했다.
- `Loom`, `Pi`, `CLI`, `Node.js`, `PPT`, `GPT`, `망고보드`, `42dot` 등은 세 전사 결과와 대화 문맥이 함께 뒷받침할 때만 표기를 교정했다.
- 자동 화자 분리를 신뢰할 근거가 없어 임의의 화자 이름을 붙이지 않았다. 대화 전환은 하이픈으로 표시했다.
- 확정하기 어려운 사람 이름, 짧은 문장과 화면 지시어는 내용을 만들어내지 않고 불명확 표기로 보존했다.
- 원본은 수정하지 않고 각각의 최종 TXT 두 파일만 바탕화면에 추가했다.
