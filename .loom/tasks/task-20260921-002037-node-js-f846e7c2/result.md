바탕화면의 두 원본 음성을 각각 전체 길이만큼 전사해 같은 위치에 별도 UTF-8 TXT로 저장했다.

- `26-09-2_연진님_팀_대화_전사.txt`: 20분 3초, 41개 타임스탬프 구간, 16,870바이트
- `26-09-20_연진님_nodejs_세션_피드백_전사.txt`: 3분 52초, 8개 타임스탬프 구간, 3,955바이트
