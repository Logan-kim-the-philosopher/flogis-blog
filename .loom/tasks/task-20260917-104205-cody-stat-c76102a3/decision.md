# 결정

- 설치된 OpenSuperWhisper의 로컬 한국어 모델을 사용했다. 원본을 16 kHz 단일 채널 WAV 45개 구간으로 나눠 전체를 전사했다.
- 인식 결과가 유난히 짧거나 비문인 14개 구간을 1분씩 다시 나눠 비교하고, 조용한 앞부분 7개 구간을 음량 보정해 재확인했다. 반복 오인식이 있는 3개 구간도 재검수했다.
- 발화가 더 많이 잡히면서 문맥이 이어지는 결과를 선택했다. 기계적으로 반복된 문장은 제거하고 문맥상 분명한 기술 용어만 정리했다. 알아듣기 어려운 첫 구간은 추측하지 않고 표시했다.
- 사용자 요청대로 바탕화면에는 단일 전사 TXT만 저장하고, 중간 WAV·JSON 및 검증 기록은 임시 경로에 보관했다.
