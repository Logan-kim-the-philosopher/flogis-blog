# 결정

- 지정된 사담 녹음 한 건만 단독 전사하고 원본은 수정하지 않았다.
- 개인적인 대화를 담은 음성이므로 `--local-only` 정확 모드를 사용했다. OpenSuperWhisper 처리는 로컬에서 완료했고 Pi/OpenAI 문맥 검수는 사용하지 않았다.
- 약 60초 시간창마다 원본, 음질 보정, 2개의 반분 구간, 앞뒤 문맥 후보를 비교했다. 글자 수가 현저히 적거나 후보가 크게 갈린 구간은 세부 후보로 복원하고 불확실성을 남겼다.
- 직접 대조로 확정할 수 없는 이름, 도구명, 속어는 자연스러운 단어로 임의 교체하지 않고 `불명확`과 `확인 필요`로 남겼다.
