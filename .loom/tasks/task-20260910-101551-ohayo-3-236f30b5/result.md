## 검증 근거

- `ffprobe`로 입력 3건의 AAC·44.1 kHz·mono 속성과 길이 `00:07:25`, `01:14:23`, `00:14:35`를 확인했다.
- OpenSuperWhisper JSON 원시 전사가 세 건 모두 비어 있지 않음을 확인했다.
- 74분 구조 회의는 10분 단위 8구간으로 재전사했고, 겹침이 심한 방향성 회의는 2분 단위 추가 전사로 대조했다.
- 최종 파일은 각각 7,045바이트·49줄, 53,864바이트·261줄, 7,324바이트·56줄이다.
- 세 대상 파일을 임시 최종본과 `cmp -s`로 비교해 모두 `MATCH`임을 확인했다.
- 각 파일에 제목, 원본·길이·엔진 정보, `전사 본문`, 실제 구간 제목, `확인이 필요한 내용`이 있는지 검사했다.
- `loom task validate task-20260910-101551-ohayo-3-236f30b5 --strict --json`과 `loom validate --strict`가 통과했다.
- 원본 음성은 변경하지 않았고 외부 모델 전송이나 Sanity 게시를 하지 않았다.

## 남은 위험과 다음 행동

- 여러 화자와 주변 대화가 겹친 일부 구간은 화자 분리와 정확한 표현을 확정할 수 없어 문서에 명시했다.
- 사용자는 세 Markdown을 바로 사용할 수 있으며, 해당 불명확 구간이 중요하면 원음을 들으면서 표시된 부분만 사람이 최종 대조하면 된다.
