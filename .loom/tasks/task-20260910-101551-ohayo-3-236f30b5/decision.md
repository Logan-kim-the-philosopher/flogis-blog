# 결정

## 전사 방식

- 사용자 요청과 기존 로컬 설정을 따라 OpenSuperWhisper만 사용하고, 선택된 `ggml-large-v3-turbo.bin` 한국어 모델을 변경하지 않았다.
- 장시간 오디오를 한 번에 처리했을 때 무음부에서 반복 오인식이 나타나, 74분 파일은 실제 시각 기준 10분 단위로 나눠 다시 전사한 결과를 채택했다.
- 다중 화자 겹침이 큰 14분 파일은 2분 단위 전사를 추가해 기존 결과와 대조하고 더 일관된 발화를 채택했다.

## 교정 원칙

- 발화 순서와 의미를 보존하고 내용을 요약문으로 바꾸지 않았다.
- 같은 폴더의 `OHAYO_구조_가이드.md`, `OHAYO_작업_디버깅_입문_가이드.md` 등으로 확인 가능한 `OHAYO`, `Loom`, `React`, `Django`, `Serializer`, `ORM`, `REST API`, 상태 코드만 교정했다.
- HTTP Method 불일치 예시는 문맥과 기준 문서에 따라 자동 인식의 `409`를 `405`로 교정했다.
- 화자 이름은 추정하지 않았고, 문맥으로도 확정할 수 없는 발화는 만들지 않고 `[불명확]` 표시를 사용했다.
- Pi 인증이 유효하지 않은 상태였고 회의 내용의 외부 전달이 불필요하므로 모든 음성 처리와 문맥 검수는 로컬에서 수행했다.

## 산출물 범위

- 사용자가 요청한 동일 경로 Markdown 3개만 생성했다.
- 원본 음성 변경, 다른 파일 전사, 모델 설치·삭제, Sanity 게시, 원격 Git push는 수행하지 않았다.
