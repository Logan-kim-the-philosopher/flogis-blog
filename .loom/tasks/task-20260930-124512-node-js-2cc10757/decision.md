# 결정

- 발표 녹음이므로 외부 모델을 사용하지 않고 `--local-only`로 처리했다.
- 약 60초 단위 70개 구간마다 `original`, `enhanced`, `context`, `fine-a`, `fine-b` 후보를 생성했다.
- 각 구간의 `original`과 `enhanced`를 중심으로 비교하고, 둘이 다르거나 짧게 끊긴 구간은 `fine-a`, `fine-b`로 문장 경계와 용어를 확인했다.
- 바탕화면 개인 문서의 `Nodejs_생태계_입문_v6_리허설반영_발표대본.md`가 같은 발표의 대본임을 확인하고, 실제 후보와 일치하는 본편 기술 용어 교정에만 사용했다.
- 대본 문장으로 실제 발화를 대체하지 않고, 현장에서 추가된 설명과 질의응답을 유지했다.
- 후보와 대본으로도 확정되지 않는 조용한 도입부, 사람 이름, 현장 질문 표현은 추정하지 않고 `[불명확: ...]`으로 남겼다.
- 출력 이름은 원본을 찾기 쉽게 유지한 `26-09-30_node.js세션_발표_전사.txt`로 정했다.
