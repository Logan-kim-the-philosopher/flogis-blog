# 문제 해결 기록

- 검증용 오디오 350개 준비와 로컬 일괄 추론을 합쳐 약 39분이 걸렸지만 정상 완료됐다. 모델 추론 단계는 약 33분이었다.
- 녹음 시작 후 약 3분 동안은 짧은 인사·감사 외 발화가 거의 없어 1~3번 구간의 후보가 매우 짧거나 환각 문장을 만들었다. 명확한 인사 외에는 불명확 구간으로 표시했다.
- 일부 후보가 비정상적으로 짧았다. 20번 `original`은 58자였지만 `enhanced`는 365자였고, 52·57번 `fine-b`는 각각 6자였다. 해당 구간은 온전한 다른 후보를 선택했다.
- 본편의 기술 용어는 로컬 발표 대본과 일치 여부를 확인해 교정했으나, 대본에 없는 질의응답 60~66번 구간은 불확실 표시를 유지했다.
- 작업을 막는 오류나 후속 조치는 없다.
