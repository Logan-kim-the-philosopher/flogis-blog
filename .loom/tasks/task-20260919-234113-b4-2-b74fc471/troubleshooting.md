# 문제 해결 기록

- 원음 2분 전사에서 약 8~14분, 32~38분 구간의 작은 목소리가 일부 누락됐다. 동일 음성을 1분 단위로 나누고 `highpass=f=100,dynaudnorm=f=150:g=21`로 보정해 재전사했다.
- 짧은 보정 구간에서 반복 문구와 환각성 문장이 생겨 원음 결과와 대조했다. 차이가 큰 구간은 더 긴 문맥과 완화된 음량 보정으로 세 번째 확인 전사를 수행했다.
- 확정할 수 없는 짧은 발화는 문맥으로 만들어내지 않고 불명확 표기로 보존했다.
- OpenSuperWhisper 실행 과정에서 저장소 루트에 생성된 `default.profraw`는 전사 도구의 임시 프로파일 산출물임을 확인하고 제거했다.
