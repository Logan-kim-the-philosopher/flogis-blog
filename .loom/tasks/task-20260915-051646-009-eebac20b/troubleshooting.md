# 실행 중 문제와 해결

OpenSuperWhisper가 제한된 실행 환경에서 종료 코드 134로 중단됐고 오류 로그는 비어 있었다. 필요한 실행 권한 검토를 통과한 뒤 같은 로컬 명령을 다시 실행하여 전사와 재검수를 정상 완료했다.

5분 단위 결과의 반복 문구와 일부 발화 누락을 1분 단위 대조로 보완했다. 앱의 VAD 로그에 음수 시작 시각이 표시되어 최종 파일에는 실제 PCM 구간 길이의 누적 시각을 사용했다.

실행 중 저장소에 생성된 `default.profraw`는 이번 앱 실행의 임시 산출물이므로 제거했다. 요청한 파일 저장 및 비파괴 검증에 남은 차단 사항은 없다. 불분명한 발화는 전사 파일에 재확인 표시를 남겼다.
