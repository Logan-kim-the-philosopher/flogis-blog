# 결정

- 원본을 16 kHz 단일 채널로 변환해 2분 구간 14개를 전사했다. 같은 원본의 음량을 보정한 1분 구간 27개도 로컬 OpenSuperWhisper 모델로 전사해 비교했다.
- 대부분은 원본 음질의 긴 구간 결과를 유지했다. 짧은 구간 결과에서 발화가 더 분명하거나 누락이 적은 네 구간은 보정 결과로 대체했다. 한 구간의 기계적인 반복 발화는 제거했다.
- 확인하기 어려운 인명은 파일명이나 문맥만으로 임의로 통일하지 않았다. 두 결과가 뒷받침하는 문맥상 명확한 오인식만 정리했다.
- 사용자 요청대로 바탕화면에는 단일 전사 TXT만 저장하고 중간 전사 JSON·WAV와 검증 기록은 임시 경로에 보관했다.
