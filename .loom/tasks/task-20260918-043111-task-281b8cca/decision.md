# 결정

- 각 원본을 16 kHz 단일 채널로 변환해 2분 구간(회의 23개, 사담 14개)을 전사했다. 같은 원본을 음량 보정한 1분 구간(회의 45개, 사담 27개)으로 다시 전사해 구간별로 비교했다.
- 사담은 주변 소리와 겹치는 구간이 있어 소음 보정한 2분 구간 14개도 추가로 전사했다. 원본 순서와 맥락을 유지하면서 발화가 더 분명하게 잡힌 구간의 결과를 선택했다.
- 회의의 기계적인 반복 인식은 하나의 불명확 표기로 대체했다. 사담의 확정하기 어려운 구간은 표시하고, 인명은 주어진 파일명과 일관되는 범위에서만 정리했다.
- 사용자 요청대로 하나의 통합본을 만들지 않고 각 원본에 대응하는 별도 TXT 두 파일을 바탕화면에 저장했다. 중간 오디오·모델 출력·검증 JSON은 임시 경로에만 보관했다.
