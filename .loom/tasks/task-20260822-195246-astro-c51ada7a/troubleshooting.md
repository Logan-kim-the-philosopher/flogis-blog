# 문제 해결 기록

## npm 설치 지연

- 샌드박스 내부 `npm ci`가 레지스트리 접근 중 장시간 정지했다.
- 설치 디렉터리가 생성되지 않은 것을 확인하고 프로세스를 중단한 뒤, 네트워크 접근 권한이 있는 환경에서 다시 실행해 성공했다.

## Astro background 상태 오판

- 권한 있는 호스트에서 시작한 서버를 샌드박스의 `astro dev status`와 `curl`로 확인하면 미실행처럼 보였다.
- 호스트 측 `lsof`, `curl`, `astro dev status`로 확인한 결과 앞선 서버들은 실제로 실행 중이었다.
- 제가 시작한 중복 PID `56697`, `57305`, `57607`, `58332`를 확인해 종료하고 포트가 비었는지 검증했다.
- 공식 `astro dev --background`를 다시 실행해 PID `59087`, 포트 `4321`의 단일 인스턴스로 정리했다.

## 설치 경고

- `@sanity/import@6.0.3`이 `@sanity/client` 8.x와 peer 범위가 맞지 않는다는 경고가 있다.
- Node `v25.9.0`은 `nanoid@6.0.1`의 지원 범위 `^22 || ^24 || >=26`에 포함되지 않는다.
- 현재 dev 서버 실행에는 영향을 주지 않았지만, 장기적으로 Node 24 LTS 또는 26 이상 사용을 검토할 수 있다.
