# 주요 결정

- 앞선 전사와 같은 OpenSuperWhisper 로컬 `whisper` 엔진, `ggml-large-v3-turbo.bin`, 언어 `ko`, 아시아권 자동 교정 설정을 사용했다.
- 외부 서비스에 원본이나 전사 내용을 업로드하지 않았다.
- 14분 40초 원본을 10초 중첩 두 구간으로 나눠 경계 발화 누락을 방지하고, JSON stdout을 임시 파일에 직접 저장해 출력 잘림을 막았다.
- 정리본에서는 정현님, 희성님, Cody Stat, 모두의 창업처럼 문맥상 확실한 표현만 교정하고 불확실한 구간은 표시했다. 보정 전 원시본도 함께 제공했다.
