# 실행 중 확인 사항

OpenSuperWhisper는 필요한 로컬 실행 권한 검토 후 정상적으로 25개 구간을 모두 처리했다. 앱의 VAD 로그에 실제 파일 시각과 다른 음수 시작 시각이 표시되어 최종 파일에는 PCM 구간 길이의 누적 시각을 사용했다.

한 구간에서 겹치는 음성으로 외국어 형태의 오인식이 발생해 `[전사 불가: 겹치는 음성]`으로 표시했다. 이름·일부 표현·숫자도 확정할 수 없는 경우 재확인 표시를 남겼다.

실행 중 저장소에 생성된 `default.profraw`는 이번 앱 실행의 임시 산출물이므로 제거했다. 요청한 파일 저장과 비파괴 검증에 남은 차단 사항은 없다.
