# Troubleshooting

- 두 로컬 정확 모드 실행은 오류 없이 완료됐다. 현래님 파일은 약 7분, 연진님 파일은 약 6분이 걸렸다.
- 자동 초안에서 현래님 파일의 7·15·22번 구간과 연진님 파일의 3·4·6·9·10·16번 구간에 발화 누락 또는 후보 차이가 컸다. 같은 시간창의 보정·반분·문맥 후보를 대조해 누락을 복원했다.
- 현래님 검수본을 처음 저장한 뒤 파일 맨 앞에 불필요한 3바이트 문자 `₩`가 추가되어 실행 기록의 크기·해시와 달랐다. 검수 상태를 다시 생성한 뒤 `transcribe:resume --replace`로 결과를 원자적으로 재작성했고, 파일 시작 문자열·크기·해시를 다시 검증해 일치시켰다.
- 실행 장애는 남아 있지 않다. 정밀 인용이 필요한 불확실 구간만 원음 청취로 추가 확인하면 된다.
