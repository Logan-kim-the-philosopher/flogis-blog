# 결정

- 사용자 요청의 “전부”를 블로그 저장소가 관리하는 UI·콘텐츠·문서·테스트·배포 설정 전체로 해석했다.
- 외부 식별자와 연결된 `flogy_blog`도 Jenkins, Kubernetes, 문서, 검증 스크립트에서 함께 변경해 내부 참조 불일치를 방지했다.
- `.loom` 아래 기존 실행 기록과 식별자에는 과거 사실 및 참조 무결성이 포함되므로 이름 교정 대상에서 제외했다. 현재 Task의 Loom 기록에는 변경 전후 용어가 작업 목적 설명을 위해 포함된다.
- 기존 사용자 변경인 `AGENTS.md`는 수정하거나 커밋 범위에 포함하지 않는다.
