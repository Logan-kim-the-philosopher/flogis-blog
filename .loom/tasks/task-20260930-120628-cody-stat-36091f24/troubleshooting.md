# 문제 해결 기록

- 전체 로컬 추론은 약 19분 걸렸지만 정상 완료됐다.
- 일부 후보가 비정상적으로 짧았다. 특히 25번 `original`은 36자, 33번 `original`은 246자로 다른 후보의 401~433자보다 짧아 해당 후보를 사용하지 않았다.
- 1, 3, 7, 21, 25, 31, 33, 37번 구간에서 후보 길이 차이 또는 누락이 컸다. 각 구간의 다른 후보를 대조해 가장 온전한 전사를 선택했다.
- 후보를 대조해도 분명하지 않은 15개 구간은 임의로 메우지 않고 결과에 명시했다.
- 작업을 막는 오류나 후속 조치는 없다.
