# 주요 결정

- 사용자가 설치해 둔 OpenSuperWhisper의 현재 설정을 존중했다. 설정은 로컬 `whisper` 엔진, `ggml-large-v3-turbo.bin`, 언어 `ko`, 아시아권 자동 교정 활성화 상태였다.
- 외부 서비스에는 원본 또는 전사 내용을 업로드하지 않고 모든 디코딩과 추론을 로컬에서 수행했다.
- 51분 전체 파일 한 번만 전사한 결과는 CLI 구간 로그가 45분에서 끝나 전체 커버리지를 확정하기 어려웠다. 원본을 10초 중첩 10분 단위 6개 WAV로 나누고 모델을 한 번만 로드하는 `bench` 모드로 다시 전사했다.
- 긴 콘솔 출력의 중간 잘림을 발견한 뒤 최종 재실행에서는 JSON stdout을 임시 파일에 직접 보존해 완전성을 확보했다.
- 읽기 쉬운 정리본과 보정 전 원시본을 함께 제공했다. 정리본에서는 Loom, Flogi, Cody Stat, GitHub, 모두의 창업 등 문맥상 확실한 고유명사만 교정하고 추측 위험이 있는 내용은 `[불명확]`으로 남겼다.
- 10초 중첩 부분은 양쪽 결과가 명백히 같은 경우에만 제거했다.
