# 결정

- 사용자 지시에 따라 연진님과 현래님 파일은 합치지 않고 각각의 Task와 TXT로 처리한다.
- 외부 Pi 모델 검수가 포함된 실행은 자동 승인 검토에서 거부됐다. 전사 후보 텍스트의 외부 전송이 사용자 요청에 포함되지 않았다는 사유이므로 같은 실행을 우회하지 않고 `--local-only`로 로컬 전사했다.
- 정확 모드의 5개 후보를 시간창마다 비교해 명확한 누락만 복원하고, 확정할 수 없는 발표 문구·용어·이름은 추정하지 않고 `확인 필요`로 남겼다.
- 자동 로컬 초안을 만든 뒤 같은 run의 검수 결과를 교체하고 `--local-only --replace`로 이번 Task가 만든 TXT만 갱신했다. 원본과 모델 설정은 유지했다.
