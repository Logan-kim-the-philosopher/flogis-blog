# Troubleshooting

- 처음 `npm run transcribe` 실행은 자동 승인 검토에서 거부됐다. 이유: 로컬 전사 뒤 Pi/OpenAI 검수로 음성 파생 텍스트가 외부 전송될 수 있는데 사용자가 그 전송을 승인하지 않았음.
- 명시적으로 외부 전송을 끄는 `--local-only`로 다시 실행했다. OpenSuperWhisper 후보 90개를 로컬에서 생성하고 Codex가 텍스트 후보를 교차 검토했다. Pi CLI는 호출되지 않았다.
- 원본 패스의 일부 기술 용어와 사람 이름이 후보마다 달랐다. 이를 10개의 `확인 필요` 표기로 보존했다.
- 이후 실행 장애는 없다. 원음 청취 수준의 확정이 필요한 곳은 결과 파일에 표시됐다.
