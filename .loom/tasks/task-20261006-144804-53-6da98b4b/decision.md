# 작업 결정

- 원본을 직접 편집하지 않고 `ffmpeg`로 모노 16kHz PCM 파생본을 정확히 3,180초로 만들었다. 이 방식으로 요청한 53분 경계를 고정하고 원본 무결성을 보존했다.
- 정확도 우선 모드의 60초·30초 후보를 비교하고, 유사도가 낮거나 후보 길이 차이가 큰 29개 구간은 20초 단위로 다시 전사해 사람이 문맥 검수했다.
- Pi OAuth가 기존에 만료된 상태임을 알고 있었으므로 실패가 예상되는 외부 검수를 반복하지 않고 `--local-only` 후보 생성과 Codex 수동 교차 검수를 사용했다.
- `Teams`, `Playground`, `Vercel`, `Observability`, `Kubernetes`, `PVC`, `NFS`, `Samba`, `Grafana`, `Discord`, `Jira`, `API` 등 문맥상 확정 가능한 기술 용어는 표기를 통일했다.
- 확신이 낮은 발화는 그럴듯한 문장으로 보정하지 않고 확인 필요 표시를 유지했다.
- 사용자가 지정한 `00:53:00` 이후 내용은 전사에 포함하지 않았다.
