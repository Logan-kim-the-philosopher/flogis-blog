# 결정

- 지정된 회의 음성 한 건만 별도 타임스탬프 TXT로 전사했다. 원본은 수정하지 않았다.
- 앞선 전사에서 자동 승인 검토가 Pi/OpenAI 외부 검수로 음성 파생 텍스트가 전송될 수 있다는 이유로 해당 경로를 거부했다. 이를 우회하지 않고 이번 작업도 `--local-only`로 OpenSuperWhisper 후보만 생성했다.
- 다섯 후보를 시간창마다 비교하고 원본 후보가 빠뜨린 문장을 다른 로컬 후보에서 복원했다. 일치하지 않는 이름·도구명·숫자는 추정하여 확정하지 않고 `확인 필요`로 남겼다.
- 이번 Task가 만든 자동 초안 TXT를 `--local-only --replace`로 검수본으로 갱신했다. 모델 설정과 원본 녹음은 그대로 뒀다.
