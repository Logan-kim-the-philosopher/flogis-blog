# 결정

- 이미 구축된 전사 전용 에이전트의 `accurate` 모드를 사용하고, 대상 파일 이외의 음성은 처리하지 않았다.
- Pi CLI의 인증 오류가 발생했지만 OpenSuperWhisper 후보 105개는 완성되어 있었다. 모델 설치나 로그인 설정을 변경하지 않고 보존된 원본·향상·세부·문맥 후보를 직접 비교해 전사를 완성했다.
- 원본 후보에 빠진 문장은 향상본과 세부 구간이 일치하는 범위에서 복원했다. 근거가 갈리는 과제명·번호, 일부 짧은 대화, 기술 용어는 추측으로 확정하지 않고 `[불명확]`과 `확인 필요`로 남겼다.
- 기존 결과 파일이 없음을 확인하고, 에이전트의 재개 흐름을 사용해 `<원본명>_전사.txt`를 원자적으로 만들었다. 원본 음성과 전사 엔진 설정은 바꾸지 않았다.
- 최종 결과의 처리 표시는 Pi 자동 검수가 실제로 실행되지 않았음을 드러내도록 `로컬 전사만`으로 남겼으며, 작업 기록에서 Codex 후보 대조를 별도로 명시했다.
