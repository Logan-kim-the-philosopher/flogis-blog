# 문제 해결 기록

- 샌드박스 안에서 OpenSuperWhisper CLI를 실행하면 AppKit의 `_RegisterApplication`에서 `SIGABRT` 종료 코드 134가 발생했다. macOS 앱 실행 권한을 승인받아 같은 로컬 명령을 다시 실행하자 정상 완료됐다.
- `ffprobe`에 두 입력을 한 번에 전달한 첫 구간 검사 명령이 입력 인자 오류로 실패했다. 파일별 병렬 검사로 즉시 재실행해 두 구간 길이를 확인했다.
- 12분 전체 통합 전사는 후반의 작은 목소리 일부를 생략했다. 5초 중첩 2분 구간 6개를 추가 전사해 후반 일정·식사·인원 대화를 보완했다.
- 실패한 첫 CLI 실행이 저장소 루트에 만든 0바이트 `default.profraw`를 제거했고 사용자 파일 변경은 남기지 않았다.
